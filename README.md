# Proyecto de Titulación — Ciencia de Datos

## Descripción

Proyecto de titulación de la Licenciatura en Ciencia de Datos del Instituto Tecnológico Autónomo de México (ITAM).

**Área de investigación:** Movilidad urbana en la Ciudad de México.

**Tema preliminar:** Optimización de la expansión del sistema Ecobici.

## Objetivo

Desarrollar un análisis basado en Ciencia de Datos que permita evaluar y proponer ubicaciones para la expansión del sistema Ecobici en la Ciudad de México, considerando factores de demanda potencial, accesibilidad y cobertura territorial.

## Metodología

La metodología específica se definirá conforme avance la investigación y se validará con los asesores académicos.

## Estructura

- `data/`: Datos originales, intermedios y procesados.
- `notebooks/`: Análisis exploratorios y experimentos.
- `src/`: Código Python reutilizable.
- `outputs/`: Resultados, visualizaciones y mapas.
- `docs/`: Documentación del proyecto.
- `tests/`: Pruebas de código.

## Estado

Configuración inicial del entorno de desarrollo.
